# ADR-0156: M152 scope — the cursor seam names the hover before the first click

- **Status:** Accepted (2026-11-24)
- **Implements:** the pointer's own vocabulary, the seam the widget tier was missing. Through M151 the workspace named the mouse's position (`PointerEvent`), the IME's caret, and the inspector's replay cursor — and a repo-wide search for `CursorIcon` answered nothing at all: the window's cursor shape had no door anywhere. A link read as bare text under the pointer, a text field gave the arrow no hint, and a canvas-tier drag face could not show the hand a draggable face speaks — the affordance the pointer carries was the one channel the framework never wired.
- **Companion:** ADR-0020 (the clipboard seam — the layering discipline this seam holds: the vocabulary in core, the window call in the platform), ADR-0019 (the pointer route — the deepest-accepting-hit walk the hover resolves through), §10.3 (the IME request's delta discipline — the application rule this seam rides); architecture §10.1, §18 (the M152 row).

## Decision

M152 gives the widget tier one declared word and the platform one applied fact. The vocabulary lives where the widget contract lives: [`CursorStyle`](../../crates/alacer-core/src/cursor.rs) in a new `alacer-core::cursor` module — the honest CSS-parity subset of the window system's own icon set (winit's `CursorIcon`, the names the web's `cursor` property taught), every style mapping one-to-one and none invented, the wire tag the `name()` discipline every fact enum carries. The single-edge resizes (`e_resize`, `n_resize`, …) are deliberately absent: they are the window chrome's own words (winit maps them from `ResizeDirection`), never a widget's declaration — the two-axis, column, and row resizes ride beside them. The widget declares through the defaulted hook the trait contract already carries: [`Widget::cursor_style`](../../crates/alacer-core/src/widget.rs) answers the default arrow unless the widget names its face — a link reads as the pointer, a text field as the text caret, the stock words shipping in `alacer-widgets` once and every consumer inheriting them. The pipeline resolves through [`PassPipeline::cursor_at`](../../crates/alacer-core/src/passes.rs): the pointer route's own walk (the same pre-order bounds sweep, the same deepest-accepting-hit chain — the hover the cursor names is exactly the hover the clicks land on, two vocabularies one geometry), a pure read that opens no pass, queues no dirt, streams no trail. The platform applies the delta: `render_frame` resolves the hover beside the IME request and calls the window only when the shape moved ([`cursor_icon_of`](../../crates/alacer-platform/src/lib.rs), the exhaustive mapping; the `applied_cursor` bookkeeping the `applied_ime` discipline rides), the leave resetting the shape itself — the frame resolves at the last position, so the pointer's exit is the platform's fact, never the stale hover's. Not in this milestone: the cursor as a fact on the inspect trail (the door resolves per frame; a trail tier prices its own record first — the M-merger rule every trail's cut has held), a hover state machine for widgets (the `PointerEvent::Move` stream is the hover's own currency; a second one would be a second truth), cursor styles riding `rsx!` props (the hook is the widget's door; a prop would name a shape the element cannot carry honestly).

## Consequences

- **A widget author names a hover in one overridden method.** The seam's cost at the widget tier is the hook's own: declare `CursorStyle::Grab` on a grab handle and the pointer answers it — no registry, no props, no platform dependency in any widget's set (the clipboard seam's layering held exactly).
- **The affordance channel is wired end to end.** Core carries the vocabulary, the pipeline resolves the hovered word from the geometry it already walks, and the platform applies the delta to the window — the ADR-5 rule at the cursor tier: a widget that overrides nothing declares nothing, and the default is the honest absence, never a guessed affordance.
- **The per-frame price is a walk the route already pays, and it is priced.** The hover resolution reuses the pointer route's own pre-order sweep (two vocabularies, one geometry — the route's cost is not doubled by a second walk), and `benches/cursor.rs` joins the published corpus with `cursor_at_deepest_hit_200` and `cursor_at_void_200` (the styled leaf's answer beside the void's), the regression gates riding in the same cut (the coordinated rule, the M5 corpus discipline — the pins re-agreeing at 163 with M153's cases in the same sweep). [`examples/cursor_styles.rs`](../../crates/alacer/examples/cursor_styles.rs) drives the composition from the consumer side: the link, the field, the label that declares nothing, and the custom handle that names its own shape, the applied deltas tracing at `alacer::platform` under `RUST_LOG=alacer=debug`.
