# ADR-0157: M153 scope — the cursor trail streams the hover's resolved changes

- **Status:** Accepted (2026-11-24)
- **Implements:** the cursor tier's observability, the fact tier every other seam carries. M152 named the hover's shape and the platform applied it, and the only observer of the churn was the platform's own debug line: "why did the pointer become a hand?" was a resolve-the-door-twice-and-diff-by-hand question, the work every other tier's trail removed — the edit trail's shape (ADR-0037), the clipboard trail's (ADR-0045), the value tier's (ADR-0046), the theme tier's (ADR-0079) — and the cursor seam shipped without its member.
- **Companion:** ADR-0156 (the cursor seam — the resolution door whose answer this trail notes), ADR-0045 (the clipboard trail — the ring shape this tier rides verbatim), ADR-0010 (the wire protocol's versioning rule — the additive event kind the cursor fact rides); architecture §13.3, §17, §18 (the M153 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M153 gives the cursor seam its trail, the fact queued where the answer resolves: [`PassPipeline::cursor_at`](../../crates/alacer-core/src/passes.rs) — M152's resolution door — notes one [`CursorRecord`](../../crates/alacer-core/src/inspect.rs) when the resolved style *moves*, the style beside the source it rode (the widget whose hook named it, the node and role beside it — the lengths rule: the label never rides; the default answer's source is the honest absence, the absence named as a source, never guessed onto a widget that did not answer). The record rides a bounded thread ring ([`CURSOR_TRAIL_CAP`](../../crates/alacer-core/src/cursor.rs) = 256, oldest-first eviction — the clipboard trail's own bound) and the tick's start drain streams it as `InspectEvent::Cursor`, the clipboard drain's shape, one frame after the change, the drain emptying the queue whether an observer listens or not (a fact streams once, an absent reader just never sees it). The flood rule holds at the cursor tier: a style that did not move is not a fact — the door coalesces against the last noted answer, one record per change, never per frame, and the disabled trail's whole cost is the note's one branch (the A7 idle contract, the settings trail's own arithmetic). The wire carries the fact the additive rule admits: a `cursor` event at version 1 — `style`, `source`, and the `node`/`role` pair riding the widget source (`null` when the default answered), clients that ignore unknown kinds unaffected — the `cursors` ring joining the recorder ([`CURSOR_RING_CAP`](../../crates/alacer-inspect/src/recorder.rs) = 512), the tier joining the subscribe gate's vocabulary and the stats answer's rows (the bounds sentence's own list — the two cannot drift apart), `clear` and `replay` answering the ring like every other tier's. Not in this milestone: cursor facts as a per-frame stream (a still hover is not a fact — the coalescing is the flood rule's own answer), a cursor tier in the recorder's tree door (the hover rides the ring tier's history, never the retained shape), cursor facts riding the platform's leave (the trail notes *resolutions*; the leave is the window's fact, the platform's own debug line its observer).

## Consequences

- **"Why did the pointer's shape move?" is one drained window away.** The trail answers with the style and the face that named it — the inspector panel, a status line, or a test reads the cursor tier without re-implementing the observation at the resolution site, the note standing where the hover resolves (the clipboard note site's own discipline, one layer up).
- **The idle contract is priced, not hoped.** The disabled trail costs one branch per resolution; the live trail's two prices join the published corpus — `cursor/trail_note_on_change_200` (the note's cost under the observer it serves) and `cursor/trail_note_no_change_200` (the compare a still hover pays) — the regression gates riding in the same cut, the corpus pins re-agreeing at 163 with the M152 cases in the same sweep (the coordinated rule).
- **The wire's vocabulary grew by the additive rule.** One new event kind at version 1, one new ring and tier — the stats answer carries one more row, the gate names one more tier, and the protocol tests grow the beats: the cursor fact's wire shape over the recorder (the `wire_cursor` conversion, the default's null ids), the tier's word, the stats row the ring answers.
