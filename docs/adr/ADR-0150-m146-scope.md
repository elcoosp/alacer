# ADR-0150: M146 scope — the point ask answers which node the point touches

- **Status:** Accepted (2026-11-23)
- **Implements:** the gap the dump ask's own panel left — through M145 the inspector's panel could replay the rings' history, read their occupancy, gate the stream by tier, and dump the resolved tree's whole shape, but "which control is *this*?" was a question the wire could not ask: a panel pointing at a coordinate walked the whole dump and re-implemented the geometry client-side, the shape the AT walks queried without the locate door the query vocabulary's other doors all have.
- **Companion:** ADR-0143 (the replay ask — the response-only event's precedent), ADR-0148 (the dump ask — the retained snapshot's state door this ask rides), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M146 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M146 grows the ask family beside the dump's precedent, one control one answer: the `hit_ask` control carries a point (`[x, y]`, the tree's own logical pixels — the bounds quadruple's frame), and the answer is one `hit` event carrying the walk's landed-or-refused shape (the focus event's own): a landing names the ancestry the walk descended through — root-first, the hit node last, each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks (one shape, the two asks' doors, the two unable to drift apart) — and every refusal a named species (`no_tree`, `no_geometry`, `outside`, `malformed`), never a collapsed `false`. The geometry lives where the query vocabulary lives: [`TreeSnapshot::hit_at`](../../crates/alacer-core/src/passes.rs) beside `find`/`by_id`/`walk` — the snapshot's query vocabulary grown the one door it lacked (`find`, `by_id` and `walk` name, address, and walk; this one locates) — and the wire conversion ([`wire_hit`](../../crates/alacer-inspect/src/wire.rs)) maps the verdict onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The land rule is the paint order's own: among the nodes containing the point, the last in pre-order wins (the tree walk order is the paint order, later siblings composite on top, the answer names what the pixels would answer); containment is the geometry's own half-open convention (euclid's `Rect::contains`, the convention the damage tests and the scroll clamps speak). A non-finite point is refused before it corrupts: the core door names the `malformed` species before the comparisons run (the scroll tier's NaN rule — euclid's containment would munge NaN into a plain outside miss), and on the wire a non-finite ask is already the malformed frame's close (JSON cannot carry NaN; serde renders it `null`, the array parse refuses — the documented report-and-close behavior). The secret-carrying rule stands: the answer is the shape (role, label, bounds, availability, parentage), the contents — a field's value, its selection, the placeholder and description beside them — have no key in the ancestry at all, the dump ask's rule at the point tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `hit_ask/answer_1k_nodes` bench (the geometry query, the wire conversion, the serialization — the answer's whole worth over the same 1 000-node resolved tree the dump's price walks) joins the published corpus with its regression gate in the same cut (the coordinated rule: every bench and its baseline land together — the M5 exit suite's own contract, and the corpus pins re-agreeing at the cut). Not in this milestone: region/rect asks (a second geometry vocabulary, priced first when a consumer needs the shape between two points), hit asks bounding input routing (the pipeline's own funnel stays the pipeline's — the ask answers the snapshot the AT walks, never re-routes the dispatch).

## Consequences

- **A panel can ask "which control is this?" in one ask.** The point the tester's harness or the operator's eye lands at crosses the wire once and answers with the node the AT walks beside the ancestry that reached it — the panel folds the answer into the shape the dump ask already gave it (the node vocabulary is the tree event's own), or reads it standalone (the ancestry names the walk it descended).
- **The query vocabulary is whole.** `find` names, `by_id` addresses, `walk` enumerates, `hit_at` locates — the four doors one snapshot carries, the testing harness and any consumer asking the same vocabulary the wire asks. The refusals are species, the landing is a shape: the same landed-or-refused discipline the focus walk carries, at the geometry tier.
- **The corpus grew by the coordinated rule.** The hit ask's answer price is a connect-time price beside the burst's and the dump's, never a per-frame one — the point rides no broadcast, the observer's door retains the shape as state, the ask is the only door the verdict crosses the wire through. The protocol tests grow the beats (the landing over the real socket, the outside and no-tree misses, the occupancy standing across the ask, the non-finite ask's close), the m-suite's document pins re-agree at the cut, and `examples/inspector_hit.rs` drives the composition from the consumer side (the shape ask feeding the point ask — the ask family inviting the two doors to compose).
