# ADR-0153: M149 scope — the path ask answers where the node stands

- **Status:** Accepted (2026-11-23)
- **Implements:** the gap the ask family's own answers left — through M148 the panel could dump the shape, locate a point, search the names and touch a region, but "where does *this* node stand?" was still a walk-the-dump-and-climb-by-hand question: the ancestry `hit_at` names on a landing was answerable only through the point that landed there, and the id a dump, a find or a hit already carried had no door of its own.
- **Companion:** ADR-0150 (the point ask — the landed-or-refused shape and the ancestry the walk names, this ask's shape at the address tier), ADR-0151 (the word ask — the matches whose ids the path ask rides), ADR-0152 (the region ask — the ask family's newest member beside this one), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M149 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M149 grows the ask family beside the point's precedent, one control one answer: the `path_ask` control carries a node id (the one the dump, the find and the hit answers already name — the ask family composing), and the answer is one `path` event carrying the ancestry — the chain the asked node stands in, root-first, the asked node last, each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks, the ask echoed beside the answer (the point ask's echo rule at the address tier). The ancestry lives where the query vocabulary lives: [`TreeSnapshot::ancestry_of`](../../crates/alacer-core/src/passes.rs) beside `hit_at`/`hit_region`/`search` — the snapshot's query vocabulary grown the address-of door (`by_id` names the node; this one names the walk that reaches it) — and the wire conversion ([`wire_path`](../../crates/alacer-inspect/src/wire.rs)) maps the verdict onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The landed-or-refused shape is the point ask's own: a landing names the chain (the root's ancestry the root alone), every refusal a named species ([`PathMiss`](../../crates/alacer-core/src/passes.rs) — `no_tree` before the first a11y pass resolved a tree, `no_node` for an id naming nothing standing), never a collapsed `false`. The chain is the parentage the resolved tree carries — one pass over the nodes mapping every child to the parent that carries it, the walk `hit_at` descends with rebuilt from the snapshot's own shape — and the secret-carrying rule stands: the answer is the shape, the contents (a field's value, its selection, the placeholder and description beside them) have no key in the chain at all, the dump ask's rule at the address tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `path_ask/answer_1k_nodes` bench (the parentage pass, the chain rebuild, the wire conversion, the serialization — over the same 1 000-node resolved tree the dump's, the point's, the word's and the region's prices walk) joins the published corpus with its regression gate in the same cut (the coordinated rule, the M146 cut's own shape), the corpus pins re-agreeing at the cut. Not in this milestone: descendant and sibling asks (a second relative vocabulary, priced first when a panel needs what stands beside or beneath the node), path asks streaming on structure changes (the rings are the change surface — the `STRUCTURE` mask's trail answers "when did it move", the ask answers "where does it stand now", two doors one truth).

## Consequences

- **A panel can ask "where does this stand?" in one ask.** The id the dump, the find or the hit answer carried crosses the wire once and answers with the chain that reaches the node — the breadcrumb the panel walked client-side now data: root-first, the asked node last, the composite walk's own path.
- **The ask family composes.** The word ask names the node, the path ask walks to it — the two doors one workflow (`examples/inspector_path.rs` drives exactly that composition from the consumer side), the id the one currency every ask speaks. The refusals are species, the landing a shape: the landed-or-refused discipline the focus walk and the point walk carry, at the address tier.
- **The corpus grew by the coordinated rule.** The path ask's answer price is a connect-time price beside the family's, never a per-frame one — the id rides no broadcast, the observer's door retains the shape as state, the ask is the only door the chain crosses the wire through. The protocol tests grow the beats (the chain over the real socket, the unknown id's `no_node` miss, the honest absence before any frame, the occupancy standing across the ask), the m-suite's document pins re-agree at the cut, and the round-trip pin (`path_miss_names_the_species_the_wire_speaks`) keeps the species' words unable to drift from the document's.
