# ADR-0151: M147 scope — the word ask answers which names carry the query

- **Status:** Accepted (2026-11-23)
- **Implements:** the gap the point ask's own cut left beside it — through M146 the inspector's panel could locate a coordinate and dump the whole shape, but "which controls *say* 'Save'?" was still a walk-the-dump-and-filter-by-hand question: the resolved names the tree carries were answerable only wholesale, the panel re-implementing the substring funnel the query vocabulary already owns.
- **Companion:** ADR-0150 (the point ask — the response-only event's precedent this ask rides), ADR-0148 (the dump ask — the retained snapshot's state door), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M147 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M147 grows the ask family beside the point's precedent, one control one answer: the `find_ask` control carries a query (the needle) and an optional role word, and the answer is one `find` event carrying the matches — the nodes whose resolved names carry the query, case-insensitive substring (the a11y query API's own rule), in tree order, each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks, the ask echoed beside the answer (the point ask's echo rule). The role word is optional — the bare ask answers the whole vocabulary — and the vocabulary is closed: a word outside the roles' list is a malformed control frame, the documented report-and-close behavior (the unknown control's rule, at the name tier). The query lives where the plural query lives: [`TreeSnapshot::search`](../../crates/alacer-core/src/passes.rs) beside `find`/`find_all` — one substring funnel, two doors (`find_all` is the funnel with the role always named, the two unable to drift apart), the role narrowing when named, `None` the whole vocabulary — and the wire conversion ([`wire_find`](../../crates/alacer-inspect/src/wire.rs)) maps the matches onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The role word parses through the vocabulary's own parse door: [`Role::from_name`](../../crates/alacer-core/src/widget.rs) beside `Role::name` — one vocabulary, two doors, the round-trip pin (every role's word parses back to the role it named) keeping the two unable to drift apart. An empty needle names every resolved name — the ask's honest every-node answer, never a refusal; an empty matches list the honest absence (no tree resolved yet, or no name carried the needle) — the replay burst's empty answer, at the name tier. The secret-carrying rule stands: the query reads the resolved names — never the values, the selections, the hints — the content keys absent from the shape, not empty, the dump ask's rule at the name tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `find_ask/answer_1k_nodes` bench (the substring funnel, the wire conversion, the serialization — the matches' whole worth over the same 1 000-node resolved tree the dump's and the point's prices walk) joins the published corpus with its regression gate in the same cut (the coordinated rule, the M146 cut's own shape), the corpus pins re-agreeing at the cut. Not in this milestone: regex or attribute-scoped queries (a second matching vocabulary, priced first when a consumer needs more than the names the AT walks by), find asks streaming on tree changes (the rings are the change surface — a gated live stream answers "when did it appear", the ask answers "what is there now", two doors one truth).

## Consequences

- **A panel can ask "which controls say 'Save'?" in one ask.** The word crosses the wire once and answers with the matching nodes in tree order — the panel folds the matches into the shape the dump ask already gave it (the node vocabulary is the tree event's own), or reads them standalone: the roles, the resolved names, the bounds, the availability, the parentage each match rides.
- **The role vocabulary speaks both ways.** `Role::name` words a role; `Role::from_name` parses the word back — the wire's word ask rides the parse door, the diagnostics and the tooling the same door, the round-trip pin the drift guard. The vocabulary the stats rows, the heatmap, the dump answer and now the find ask speak is one vocabulary, closed and pinned.
- **The corpus grew by the coordinated rule.** The word ask's answer price is a connect-time price beside the burst's, the dump's and the point's, never a per-frame one — the word rides no broadcast, the observer's door retains the shape as state, the ask is the only door the matches cross the wire through. The protocol tests grow the beats (the narrowed matches over the real socket, the whole vocabulary's bare ask, the honest absence before any frame, the unknown role word's close, the occupancy standing across the ask), the m-suite's document pins re-agree at the cut, and `examples/inspector_find.rs` drives the beats from the consumer side (the narrowed word, the bare vocabulary, the empty answer — the ask family's three honest shapes).
