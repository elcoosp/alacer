# ADR-0152: M148 scope — the region ask answers which nodes the rect touches

- **Status:** Accepted (2026-11-23)
- **Implements:** the gap the point ask's own cut pre-registered — through M147 the panel could locate a coordinate and search the resolved names, but "which controls stand in this band of the screen?" was still a walk-the-dump-and-intersect-by-hand question: the geometry between two corners was answerable only point-wise, the panel re-implementing the intersection the geometry's own convention already speaks.
- **Companion:** ADR-0150 (the point ask — the plural sibling this ask rides beside, and the cut that pre-registered region asks), ADR-0151 (the word ask — the echoed-ask shape at the plural tier), ADR-0148 (the dump ask — the retained snapshot's state door), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M148 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M148 grows the ask family beside the point's precedent, one control one answer: the `region_ask` control carries a rect (`[x, y, width, height]`, the tree's own logical pixels — the bounds quadruple's frame), and the answer is one `region` event carrying the matches — the nodes whose bounds intersect the rect, in tree order (pre-order, the paint order's own), each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks, the ask echoed beside the answer (the word ask's echo rule at the plural tier). The geometry lives where the point's lives: [`TreeSnapshot::hit_region`](../../crates/alacer-core/src/passes.rs) beside `hit_at` — the snapshot's query vocabulary grown the shape-between-corners door (`hit_at` locates a point; this one answers the region) — and the wire conversion ([`wire_region`](../../crates/alacer-inspect/src/wire.rs)) maps the matches onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The touch rule is the geometry's own intersection convention (euclid's `Rect::intersection`): a rect naming no positive area — inverted or empty extents — intersects nothing, and comparisons against a non-finite coordinate are false, so the malformed ask honestly answers the empty walk rather than a munged half (the scroll tier's NaN rule; on the wire a non-finite rect is already the malformed frame's close — JSON cannot carry NaN or infinity, the point ask's own note). An empty matches list is the honest absence — no tree resolved yet, no bounds written, or the region touching nothing standing — never a refusal (the word ask's empty answer, at the region tier). The secret-carrying rule stands: the answer is the shape (role, label, bounds, availability, parentage), the contents — a field's value, its selection, the placeholder and description beside them — have no key in the matches at all, the dump ask's rule at the region tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `region_ask/answer_1k_nodes` bench (the intersection query, the wire conversion, the serialization — the matches' whole worth over the same 1 000-node resolved tree the dump's, the point's and the word's prices walk) joins the published corpus with its regression gate in the same cut (the coordinated rule, the M146 cut's own shape), the corpus pins re-agreeing at the cut. Not in this milestone: region asks bounding input routing (the pipeline's own funnel stays the pipeline's — the ask answers the snapshot the AT walks, never re-routes the dispatch), a hit-rect overlap-ratio vocabulary (a second geometry answer, priced first when a consumer needs how much of a node the region covers, not whether it touches).

## Consequences

- **A panel can ask "which controls stand here?" in one ask.** The rect the tester's brush or the operator's eye lands on crosses the wire once and answers with the touched nodes in tree order — the panel folds the answer into the shape the dump ask already gave it (the node vocabulary is the tree event's own), or reads it standalone: the matches are the paint order's own, the composite order the pixels answer.
- **The query vocabulary is whole at the geometry tier.** `hit_at` locates a point, `hit_region` answers a region — the plural sibling the point ask's own cut pre-registered, the query doors (`find` names, `by_id` addresses, `walk` enumerates) grown without a second vocabulary. The honest absences keep their shape: the empty answer never a refusal, the malformed ask refused at the wire's parse before the door runs.
- **The corpus grew by the coordinated rule.** The region ask's answer price is a connect-time price beside the burst's, the dump's, the point's and the word's, never a per-frame one — the rect rides no broadcast, the observer's door retains the shape as state, the ask is the only door the matches cross the wire through. The protocol tests grow the beats (the touched nodes over the real socket, the empty absences over empty space and before any frame, the non-finite ask's close, the occupancy standing across the ask), the m-suite's document pins re-agree at the cut, and `examples/inspector_region.rs` drives the beats from the consumer side (the whole window, a corner region, the inverted rect's honest absence).
