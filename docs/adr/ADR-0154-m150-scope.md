# ADR-0154: M150 scope — the descendant ask answers what stands beneath

- **Status:** Accepted (2026-11-23)
- **Implements:** the gap the path ask's own cut pre-registered — through M149 the panel could dump the shape, locate a point, search the names, touch a region and walk the chain that reaches a node, but "what stands *under this* node?" was still a walk-the-dump-and-flatten-by-hand question: the subtree the dump carries wholesale was answerable only by re-implementing the walk client-side, the id a dump, a find, a hit or a path already carried having no door of its own beneath.
- **Companion:** ADR-0153 (the path ask — the landed-or-refused shape this ask rides at the beneath tier), ADR-0152 (the region ask — the plural precedent), ADR-0151 (the word ask — the echoed-ask shape), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M150 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M150 grows the ask family beside the path's precedent, one control one answer: the `descendants_ask` control carries a node id (the one the dump, the find, the hit and the path answers already name — the ask family composing), and the answer is one `descendants` event carrying the subtree — what stands beneath the asked node, tree order (pre-order, the paint order's own), each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks, the ask echoed beside the answer. The asked node itself never rides its own answer: it is the anchor the ask already names, the answer the walk the panel would have flattened. The door lives where the query vocabulary lives: [`TreeSnapshot::descendants_of`](../../crates/alacer-core/src/passes.rs) beside `ancestry_of`/`hit_at`/`hit_region`/`search` — the snapshot's relative vocabulary grown the beneath door (`ancestry_of` names the walk that reaches the node; this one names what the walk would find standing under it) — and the wire conversion ([`wire_descendants`](../../crates/alacer-inspect/src/wire.rs)) maps the verdict onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The landed-or-refused shape is the path ask's own: a landing names the subtree (a leaf's landing names the honest absence — nothing stands beneath, never a refusal), every refusal a named species — [`PathMiss`](../../crates/alacer-core/src/passes.rs), the path ask's species vocabulary shared, one species list two doors (`no_tree` before the first a11y pass resolved a tree, `no_node` for an id naming nothing standing) — never a collapsed `false`. The secret-carrying rule stands: the answer is the shape, the contents (a field's value, its selection, the placeholder and description beside them) have no key in the subtree at all, the dump ask's rule at the beneath tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `descendants_ask/answer_1k_nodes` bench (the subtree walk, the wire conversion, the serialization — over the same 1 000-node resolved tree the family's prices walk) joins the published corpus with its regression gate in the same cut (the coordinated rule, the M146 cut's own shape), the corpus pins re-agreeing at the cut. Not in this milestone: sibling asks (the beside door — the relative vocabulary's second member, pre-registered beside this one and priced first when a panel needs what stands beside the node, not beneath it), descendant asks streaming on structure changes (the rings are the change surface — the `STRUCTURE` mask's trail answers "when did it move", the ask answers "what stands beneath now", two doors one truth).

## Consequences

- **A panel can ask "what stands beneath?" in one ask.** The id the dump, the find, the hit or the path answer carried crosses the wire once and answers with the subtree — the flattened walk the panel re-implemented client-side now data: tree order, the paint order's own, the anchor left out.
- **The ask family composes deeper.** The word ask names the node, the path ask walks to it, the descendant ask reads what stands under it — three doors one workflow (`examples/inspector_descendants.rs` drives exactly that composition from the consumer side), the id the one currency every ask speaks. The refusals are species, the landing a shape: the landed-or-refused discipline the focus walk and the point walk carry, at the beneath tier.
- **The corpus grew by the coordinated rule.** The descendant ask's answer price is a connect-time price beside the family's, never a per-frame one — the id rides no broadcast, the observer's door retains the shape as state, the ask is the only door the subtree crosses the wire through. The protocol tests grow the beats (the subtree over the real socket, the leaf's honest absence, the unknown id's `no_node` miss, the honest absence before any frame, the occupancy standing across the ask), the m-suite's document pins re-agree at the cut, and the round-trip pin (`descendants_answer_*`) keeps the shape's words unable to drift from the document's.
