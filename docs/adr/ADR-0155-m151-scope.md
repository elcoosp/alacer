# ADR-0155: M151 scope — the sibling ask answers what stands beside

- **Status:** Accepted (2026-11-23)
- **Implements:** the second member the descendant ask's own cut pre-registered — through M150 the panel could dump the shape, locate a point, search the names, touch a region, walk the chain that reaches a node and read the subtree beneath it, but "what stands *beside this* node?" was still a walk-the-dump-and-filter-by-hand question: the parent's row answerable only by re-implementing the parentage client-side, the id the family's answers already carried having no door of its own beside.
- **Companion:** ADR-0154 (the descendant ask — the beneath door this ask rides beside, the relative vocabulary's two members), ADR-0153 (the path ask — the landed-or-refused shape the family carries at the address tier), ADR-0010 (the wire protocol's versioning rule); architecture §13.3, §17, §18 (the M151 row); `docs/inspector-protocol.md` (the normative wire document).

## Decision

M151 completes the relative vocabulary the path's cut pre-registered, one control one answer: the `siblings_ask` control carries a node id (the one the family's answers already name — the ask family composing), and the answer is one `siblings` event carrying the row — the parent's other children beside the asked node, tree order (pre-order, the paint order's own), each node the [`WireTreeNode`](../../crates/alacer-inspect/src/wire.rs) vocabulary the tree event speaks, the ask echoed beside the answer. The asked node itself never rides its own answer: it is the anchor the ask already names, the answer the row the panel would have filtered. The door lives where the query vocabulary lives: [`TreeSnapshot::siblings_of`](../../crates/alacer-core/src/passes.rs) beside `descendants_of`/`ancestry_of` — the relative vocabulary whole at the tier (the walk that reaches the node, the subtree beneath it, the row beside it) — and the wire conversion ([`wire_siblings`](../../crates/alacer-inspect/src/wire.rs)) maps the verdict onto the retained state the recorder keeps through the observer's tree door, exactly the dump ask's ride. The landed-or-refused shape is the family's own: a landing names the row (the root's landing names the honest absence — the root stands beside nothing, and so does an only child; an absence, never a refusal), every refusal a named species — [`PathMiss`](../../crates/alacer-core/src/passes.rs), the family's species vocabulary shared, one species list three doors (`no_tree` before the first a11y pass resolved a tree, `no_node` for an id naming nothing standing) — never a collapsed `false`. The secret-carrying rule stands: the answer is the shape, the contents (a field's value, its selection, the placeholder and description beside them) have no key in the row at all, the dump ask's rule at the beside tier. The ask reads without disturbing (the dump ask's own rule): no ring drains, the broadcast queue is untouched, the answer is the *state*, and the event prices no ring — never a captured fact, never a streamed one. The ask's price is named first: the `siblings_ask/answer_1k_nodes` bench (the parentage pass, the row rebuild, the wire conversion, the serialization — over the same 1 000-node resolved tree the family's prices walk) joins the published corpus with its regression gate in the same cut (the coordinated rule, the M146 cut's own shape), the corpus pins re-agreeing at the cut. Not in this milestone: sibling asks streaming on structure changes (the rings are the change surface — the `STRUCTURE` mask's trail answers "when did it move", the ask answers "what stands beside now", two doors one truth), a cousin/uncle vocabulary (a third relative tier — priced first when a panel needs the walk two steps out, never smuggled into the sibling ask's shape).

## Consequences

- **A panel can ask "what stands beside?" in one ask.** The id the family's answers carried crosses the wire once and answers with the row — the filtered parent's children the panel re-implemented client-side now data: tree order, the paint order's own, the anchor left out.
- **The relative vocabulary is whole.** `ancestry_of` answers the walk that reaches the node, `descendants_of` the subtree beneath it, `siblings_of` the row beside it — three doors one vocabulary, the query doors (`find` names, `by_id` addresses, `walk` enumerates, `hit_at` locates, `hit_region` answers the region) grown without a second vocabulary. The honest absences keep their shape: the root's and the only child's empty row never a refusal, the malformed ask refused at the wire's parse before the door runs.
- **The corpus grew by the coordinated rule.** The sibling ask's answer price is a connect-time price beside the family's, never a per-frame one — the id rides no broadcast, the observer's door retains the shape as state, the ask is the only door the row crosses the wire through. The protocol tests grow the beats (the row over the real socket, the root's honest absence, the unknown id's `no_node` miss, the honest absence before any frame, the occupancy standing across the ask), the m-suite's document pins re-agree at the cut, and the round-trip pin (`siblings_answer_*`) keeps the shape's words unable to drift from the document's.
